# Example: HH → bb̄ WW → bb̄ qq̄′ ℓν, against tt̄

One Higgs boson decays to two b jets, the other to a hadronic and a leptonic W; tt̄ is described as a
second hypothesis on the same objects.

* `bbww.yaml`: the event description (explained in [docs/BBWW.md](../../docs/BBWW.md)).
* `bbww_hyperparameters.yaml`: the same with every setting written out
  ([docs/Options.md](../../docs/Options.md)).
* Data: `examples/data/bbww_small.h5` (in the repository) and `bbww_all.h5` (distributed separately).

The commands are in [docs/BBWW.md](../../docs/BBWW.md).
