# Example: HH → bb̄ bb̄

Two Higgs bosons, each decaying to a pair of b jets, against multijet background.

* `hh4b.yaml`: the event description (explained line by line in [docs/HH4b.md](../../docs/HH4b.md)).
* `hh4b_hyperparameters.yaml`: the same with every setting written out at its default value
  ([docs/Options.md](../../docs/Options.md)).
* Data: `examples/data/hh4b_small.h5` (in the repository) and `hh4b_all.h5` (distributed separately).

The commands are in [docs/HH4b.md](../../docs/HH4b.md).
